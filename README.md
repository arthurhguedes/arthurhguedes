## Sobre

Estudo Inteligência Artificial na UFOP e venho me especializando em desenvolvimento full stack: back-end com Node/Express, front-end com React e TypeScript, banco de dados PostgreSQL. Uso Linux como ambiente principal de desenvolvimento e mantenho o hábito de estudar algo novo com frequência, de linguagens de sistema como C a ferramentas modernas de back-end.

Aberto a oportunidades de estágio e vaga júnior em desenvolvimento full stack.

## Projeto principal

### [Notary](https://github.com/arthurhguedes/organizador-faculdade)

<a href="https://github.com/arthurhguedes/organizador-faculdade">
  <img src="https://raw.githubusercontent.com/arthurhguedes/organizador-faculdade/main/docs/screenshots/dashboard.png" alt="Dashboard do Notary" width="100%" />
</a>

Organizador acadêmico full stack: matérias, horários, provas, notas e coeficiente calculados automaticamente. Importa dados direto dos PDFs e planilhas que a faculdade já disponibiliza, com parsing 100% no navegador (o back-end nunca recebe arquivo). Autenticação real multi-tenant, 118 testes automatizados e CI no GitHub Actions.

## Outro projeto

### [Capítulo Harmonia e Paz nº 496](https://harmoniaepaz.org)

Site institucional em produção para uma organização real: domínio próprio, deploy na Vercel, Search Console configurado. SEO técnico completo (sitemap, canonical, Open Graph, robots.txt) e headers de segurança acima do padrão para esse tipo de site (CSP restritiva, HSTS com preload, X-Frame-Options DENY, Permissions-Policy).
